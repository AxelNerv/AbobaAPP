# Свой сервер входа и синхронизации

Обычному пользователю это не нужно: адрес готового сервера уже вшит
в приложение. Этот раздел — для тех, кто хочет поднять собственный сервер
(свой Telegram-бот для входа и своя синхронизация библиотеки).

## Что понадобится

- VPS с Ubuntu (хватит 1 ядра и 1–2 ГБ памяти) и root-доступ.
- Свободный порт 80 (через него Let's Encrypt выдаёт сертификат) и порт HTTPS:
  443 или любой другой, например 8443.
- Домен. Без своего подойдёт адрес вида `203-0-113-10.sslip.io`
  (вместо точек в IP — дефисы).
- Telegram-бот: создай у @BotFather и возьми токен.

## Установка

1. Скопируй на сервер в одну папку содержимое `deploy/auth-vps` и папку
   `backend` из репозитория.
2. Рядом создай `.env` по образцу `.env.example`: `ABOBA_AUTH_DOMAIN`,
   `ABOBA_HTTPS_PORT`, `ABOBA_BOT_TOKEN`, `ABOBA_ADMIN_KEY` (длинная
   случайная строка), `ABOBA_BOT_USERNAME`, при желании `ABOBA_ADMIN_IDS`.
3. От root запусти `bash install.sh`. Скрипт поставит Docker, поднимет бота,
   сервер входа и Caddy с HTTPS, проверит адреса и напечатает адрес для
   приложения. Повторный запуск безопасен — так же обновляется код.
4. В приложении: «Настройки» → «Свой сервер…» → вставь адрес → сохранить.

## Что открыто наружу

Только вход (`/auth/init`, `/auth/poll/*`, `/auth/status`), синхронизация
(`/sync`) и чтение статуса сериалов (`GET /ext/tvmaze/*`). Всё остальное
отвечает 404. Один токен бота нельзя опрашивать двумя серверами сразу —
старый останови до запуска нового.
