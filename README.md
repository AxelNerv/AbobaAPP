# AbobaTV

Приложение для Windows, чтобы смотреть фильмы и сериалы. Каталог и плееры
берутся из внешних источников, всё остальное работает на твоём компьютере.

- Каталог, поиск и страница фильма (источник kinobd).
- Несколько встроенных плееров с автовыбором; плеер, где есть 4K, помечен значком.
- Вход через Telegram-бота.
- История, избранное и позиция просмотра (сезон, серия, таймкод) синхронизируются
  через сервер: вошёл на другом компьютере — всё подтянулось. Без сети приложение
  работает как обычно и досылает изменения позже.
- Над плеером видно, где остановился; плеер открывается на нужной серии.
- Импорт библиотеки из файла (например, истории из браузера).
- Обновления приходят сами: уведомление в колокольчике и кнопка «Установить
  обновление», без переустановки.
- Встроенный блокировщик рекламы, его можно выключить в настройках.
- Раздача по Wi-Fi: телефон в той же сети открывает приложение по адресу или QR-коду.
- Резервные копии данных и журнал — в разделе «Приложение и Wi-Fi».

## Установка

Скачай `AbobaTV-Setup-*.exe` в [Releases](../../releases) и запусти. Установщик
не подписан, поэтому Windows может показать «Система Windows защитила ваш
компьютер» — «Подробнее» → «Выполнить в любом случае».

## Стек

Electron, Vue 3 + Vite + Pinia, локальный бэкенд на FastAPI (Python 3.12) и SQLite.
В установщик входит свой Python, так что готовому EXE ничего ставить не нужно.

## Сборка

Нужны Node.js 22 с Yarn и Python 3.12 с pip (только для подготовки сборки).

```bash
yarn install --frozen-lockfile
yarn app:build
```

Установщик появится в `release`. `yarn app:unpacked` собирает папку
без установщика.

Проверки:

```bash
yarn test:unit --run
yarn lint
.pyruntime/python.exe -m unittest discover -s backend/tests
```

## Вход

Вход через Telegram. Сервер входа и синхронизации уже настроен и вшит
в приложение — ничего поднимать не нужно: установил, вошёл, смотришь.
Хочешь свой сервер со своим ботом — инструкция в [deploy/auth-vps](deploy/auth-vps/README.md).

Подробности про сборку, вход, данные и Wi-Fi — в [docs/DESKTOP.md](docs/DESKTOP.md).

## Дополнительные данные фильмов и аниме

Основной каталог и плееры работают без новых ключей. Дополнительные данные
загружаются в фоне только для открытой карточки и не задерживают видео:

- AniList: обложки, фон, число серий и длительность аниме. Ключ не нужен.
  Пользовательские списки в AniList не отправляются; массовое копирование базы не выполняется.
- TMDB: русское описание, постеры, фоны, длительность и сведения о сезонах.
- OMDb: резервный постер, длительность и IMDb-рейтинг. Бесплатный ключ ограничен
  1000 запросами в день; API не является источником видеопотоков.

Для TMDB и OMDb нужны **свои ключи**. Без ключей статус — `unconfigured`,
запросы к этим сервисам не отправляются. Создай `.env` в профиле приложения
`%APPDATA%\AbobaTV\.env` (при разработке — в корне проекта):

```dotenv
TMDB_API_KEY=свой_ключ_tmdb
OMDB_API_KEY=свой_ключ_omdb
```

После изменения перезапусти приложение. Ключи не добавляй в git, не называй их
`VITE_*` и не включай в публичный установщик. Для отдельного экземпляра приложения
используется его собственная папка профиля. Проверить настройку локального backend
можно через `GET /metadata/status` — этот ответ не содержит ключей.

Получение ключей и условия: [TMDB](https://developer.themoviedb.org/docs/faq),
[OMDb](https://www.omdbapi.com/apikey.aspx),
[AniList](https://docs.anilist.co/guide/terms-of-use).
TMDB требует указания источника при некоммерческом использовании; данные OMDb — CC BY-NC 4.0.
