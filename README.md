# AbobaTV

Приложение для Windows, чтобы смотреть фильмы и сериалы. Каталог и плееры
берутся из внешних источников, всё остальное работает на твоём компьютере.

- Каталог, поиск и страница фильма (источник kinobd).
- Несколько встроенных плееров с автовыбором; плеер, где есть 4K, помечен значком.
- Избранное и история просмотра хранятся локально.
- Вход через Telegram-бота.
- Встроенный блокировщик рекламы, его можно выключить в настройках.
- Раздача по Wi-Fi: телефон в той же сети открывает приложение по адресу или QR-коду.
- Резервные копии данных и журнал — в разделе «Приложение и Wi-Fi».

## Стек

Electron, Vue 3 + Vite + Pinia, локальный бэкенд на FastAPI (Python 3.12) и SQLite.
В установщик входит свой Python, так что готовому EXE ничего ставить не нужно.

## Сборка

Нужны Node.js 22 с Yarn и Python 3.12 с pip (только для подготовки сборки).

```bash
yarn install --frozen-lockfile
yarn app:build
```

Установщик появится в `release`. `yarn app:unpacked` собирает папку
без установщика.

Проверки:

```bash
yarn test:unit --run
yarn lint
.pyruntime/python.exe -m unittest discover -s backend/tests
```

## Вход

Бот и сервер подтверждения входа поднимаются отдельно — на своём сервере
из `deploy/auth-vps`. Адрес сервера вводится в приложении в разделе
«Приложение и Wi-Fi».

Подробности про сборку, вход, данные и Wi-Fi — в [docs/DESKTOP.md](docs/DESKTOP.md).
