# AbobaTV для Windows

## Сборка

```powershell
yarn install --frozen-lockfile
yarn app:build
```

Установщик появляется в `release`. `yarn app:unpacked` создаёт папку приложения
без установщика. `yarn app:frontend` собирает только интерфейс.
Первичная подготовка Python и загрузка инструментов сборки требуют интернета;
готовому EXE Python, Node.js и Docker не нужны.

Проверки перед сборкой:

```powershell
yarn test:unit --run
.\.pyruntime\python.exe -m unittest discover -s backend/tests -v
yarn lint
```

Для разработки запустите `yarn dev` с переменной `ABOBA_DEV=1`, затем
`yarn app` в другом терминале. Для проверки готового интерфейса без Vite:
`yarn app:frontend`, затем `yarn app:prod`.

## Вход через Telegram

Бот и сервер подтверждения входа живут на отдельном сервере, EXE не запускает
собственного бота и не содержит его токен. Приложение спрашивает подтверждение
у сервера через свой локальный бэкенд и создаёт локальный профиль по Telegram ID.
Каталог и плееры запрашивает локальный бэкенд. История, избранное и позиция
просмотра (серия и таймкод) хранятся на компьютере и синхронизируются через
сервер входа: вошёл на другом компьютере — библиотека подтянулась. Без связи
с сервером приложение работает как обычно и досылает изменения позже.

Адрес сервера по умолчанию вшивается при сборке из `electron/server.local.json`
(образец — `server.local.example.json`; сам файл в git не попадает, чтобы адрес
сервера не был виден в публичном репозитории). Свой сервер: «Настройки» → «Свой сервер…» → адрес (без `/auth/init`)
→ сохранить. Адрес можно также заранее задать через `ABOBA_AUTH_SERVER_URL`
в `%APPDATA%\AbobaTV\.env`. Без доступного адреса вход не заработает,
клиент показывает причину.

## Данные, диагностика и Wi-Fi

Профиль: `%APPDATA%\AbobaTV`. База — `data\abobatv.db`, настройки —
`settings.json`, журналы — `logs`, резервные копии — `backups`.
В разделе «Приложение и Wi-Fi» доступны журнал, копирование и восстановление.
Копии содержат пользовательские данные и сессии; храните их как личные файлы.
Ключи из `.env` в копии не включаются. Перед восстановлением создаётся копия
текущей базы; после восстановления потребуется повторный вход.

Для телефона включите раздачу и используйте показанный адрес/QR-код.
Если адаптеров несколько, доступны дополнительные адреса. В Windows сеть
должна иметь профиль «Частная»: правило брандмауэра ограничено этой сетью.
На телефоне нужно войти в тот же Telegram-профиль.

Настройка «Сворачивать в трей» позволяет закрыть окно и продолжить раздачу.
Команда «Выйти» в трее завершает приложение и локальные службы.

## Границы проверки

Сохранение серии/таймкода зависит от API конкретного встроенного плеера.
Наличие фильма в истории не доказывает сохранение позиции. Внешние плееры,
реальный Telegram-вход, телефон и чистую Windows автоматические проверки
не покрывают — их проверяют руками.
