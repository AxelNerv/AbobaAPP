# Запросы каталога

Фиксированные операции чтения для `https://graphql.kinopoisk.ru/graphql/`.
Это внутренний интерфейс сайта Кинопоиска: доступность и схема могут меняться.
Проверено живыми запросами 8 октября 2026 года без API-ключа, аккаунта и cookies.
Операции выполняются локальным бэкендом приложения; VPS обновлять не требуется.

- `SearchMovies` — поиск по названию и точные ID Кинопоиска.
- `MovieDesktopListPage` — списки `popular-films` и `popular-series`.
- `MovieDetailsMobileGeneralMeta` — название, постер, описание, страны и жанры.
- `MovieDetailsMobileRatingBase` — рейтинг Кинопоиска.

Исходные документы опубликованы в [reyohoho](https://github.com/dav2010ID/reyohoho):
`graphql_extracted/clean_graphql/queries/query/` и
`workers/kinobox-search/kinopoisk-top-query.mjs`.
Запросы хранятся в сборке; приложение не загружает их из GitHub во время работы.

Нельзя сокращать документы произвольно: сервер проверяет разрешённые операции
и отвергает изменённый запрос. Пользовательские поля отключены переменными;
токены, авторизация и персональные данные не передаются.

При отказе основного каталога сохраняются резервные источники:
Wikidata и KinoBD для поиска, KinoBD для списка, FBP и KinoBD для карточки.
Отдельная цепочка источников плеера остаётся независимой от каталога.
HTTP-ошибки и GraphQL `errors` даже с HTTP 200 не считаются пустой выдачей
и не кешируются как успешные ответы.
